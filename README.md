# Repaso

Aplicación de escritorio desarrollada en C# con Avalonia UI y el patrón MVVM. 
Su objetivo es importar documentos PDF de tipo test (como exámenes de campus virtuales o apuntes de plataformas), extraer las preguntas y opciones mediante parseo de texto, organizarlas en carpetas temáticas y permitir al usuario practicar y repasar las preguntas falladas.

## Tecnologías
- **Frontend:** Avalonia UI (XAML)
- **Backend / Lógica:** C# (.NET 8+)
- **Arquitectura:** MVVM (Model-View-ViewModel) usando CommunityToolkit.Mvvm
